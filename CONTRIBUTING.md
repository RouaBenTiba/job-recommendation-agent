# Contribution

## Branches

- main : version stable, fusion uniquement par pull request depuis develop
- develop : intégration, base des nouvelles branches
- feature/<epic>-<description> : une user story (ex. feature/epic3-adzuna-client)
- fix/<description> : correction de bug
- docs/<description>, ci/<description>, chore/<description>

## Commits (Conventional Commits)

type(portée): description courte, en anglais
Exemple : feat(agent): add strategy modification node

## Pull requests

- une pull request par user story, avec US-X.Y dans le titre
- CI verte obligatoire avant fusion
